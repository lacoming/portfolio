# Правила проекта

- После любой правки сайта в `sites/` обновляй его превью `previews/<key>.jpg` (924×520, JPEG, скрин верха страницы). Ключи: tokeon, rentsale-altay, flexpath, univer-zakupok, tersk, termy, last-signal, gastro, atelier.
- Исключение: `previews/tokeon.jpg` — курированный скрин, поверх него анимируется отдельный слой `previews/tokeon-sphere.png`. Не перезаписывать без явной просьбы.
