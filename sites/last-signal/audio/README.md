# Аудио для плеера LAST SIGNAL

Плеер на странице читает треки из этой папки. Ожидаемые имена файлов:

| Альбом | № | Название на странице | Файл |
|---|---|---|---|
| NO_FUTURE | 01 | ПЕРЕГРУЗКА | `no-future-01.mp3` |
| NO_FUTURE | 02 | ПРОТОКОЛ СОПРОТИВЛЕНИЯ | `no-future-02.mp3` |
| NO_FUTURE | 03 | БЕЛЫЙ ШУМ | `no-future-03.mp3` |
| NO_FUTURE | 04 | NO_FUTURE | `no-future-04.mp3` |
| NO_FUTURE | 05 | ФИДБЭК ОТ РЕАЛЬНОСТИ | `no-future-05.mp3` |
| PROTOCOL_SILENCE.ZIP | 01 | ОБРЫВ СВЯЗИ | `protocol-silence-01.mp3` |
| PROTOCOL_SILENCE.ZIP | 02 | ЭХО В ПУСТОТЕ | `protocol-silence-02.mp3` |
| PROTOCOL_SILENCE.ZIP | 03 | ТИШИНА.EXE | `protocol-silence-03.mp3` |
| PROTOCOL_SILENCE.ZIP | 04 | ПОСЛЕДНИЙ СИГНАЛ | `protocol-silence-04.mp3` |

Правила:

- Формат — mp3 (браузеры играют его везде). Хронометраж плеер берёт из самого файла, руками нигде не прописан.
- Файлов может быть меньше девяти: которых нет, помечаются в списке как «НЕТ ФАЙЛА» и не кликаются. Остальное играет.
- Названия треков и состав альбомов задаются массивом `TRACKS` в начале скрипта
  [`../index.dc.html`](../index.dc.html) — там же меняются имена файлов, если удобнее свои.
- Репозиторий публичный: класть сюда только то, на что есть права.
